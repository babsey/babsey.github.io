## NEST Desktop

A web-based GUI application for the NEST Simulator. Models are composed graphically, simulated
with NEST in the background, and the activity is visualised interactively.

[Source](https://github.com/nest-desktop/nest-desktop){: .btn .btn--primary}
[Legacy version](https://github.com/babsey/nest-desktop-legacy){: .btn .btn--inverse}

## Spatio-temporal activity sequences

Simulation code for spatio-temporal activity sequences in spiking neuronal networks
(Python, NEST).

[Source](https://github.com/babsey/spatio-temporal-activity-sequence){: .btn .btn--primary}

## Code Graph

A modular code generator: assemble nodes into a graph and generate code from it (TypeScript).

[Source](https://github.com/babsey/code-graph){: .btn .btn--primary}

## NEST Lab Xircuits

NEST projects for the Xircuits JupyterLab extension, for building simulations as visual
workflows inside JupyterLab.

[Source](https://github.com/babsey/nest-lab-xircuits){: .btn .btn--primary}
