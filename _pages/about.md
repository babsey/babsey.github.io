I'm Sebastian Spreizer, based in Freiburg, Germany. My work sits at the intersection of
computational neuroscience and research software engineering.

I develop [NEST Desktop](https://github.com/nest-desktop/nest-desktop), a web-based graphical
interface for the [NEST Simulator](https://www.nest-simulator.org/). It lets students and
researchers build spiking neural network models visually, run simulations and analyse the
results directly in the browser.

## Interests

- Spiking neuronal network models and their dynamics
- Spatio-temporal activity sequences
- Interactive, web-based tools for simulation and teaching
- Visual and modular code generation
